# -Laboratory-06-Cloud-Deployment-Engineer

MISSION OVERVIEW
------------------
In this mission, you will act as a Cloud Deployment Engineer at CloudNova Technologies. You will use Docker Compose to deploy a multi-container cloud storage system using Nextcloud and MariaDB.
Through this activity, you will learn to configure services using a `docker-compose.yml` file, deploy applications efficiently, and document the deployment process in your GitHub Cloud Computing Portfolio.

OBJECTIVES
-------------------
· Explain the concept of a multi-tier application architecture.
· Understand the purpose and structure of a docker-compose.yml file.
· Use a Linux command-line text editor (nano) to create configuration files.
· Deploy a multi-container application (Nextcloud + Database) using Docker Compose.
· Document deployment procedures and Infrastructure as Code (IaC) principles using Markdown.
· Continue expanding your professional GitHub Cloud Computing Portfolio.
