1. How does writing a docker-compose.yml file make a cloud engineer's job easier compared to manually typing commands?
Writing a docker-compose.yml file makes a cloud engineer's job easier because it allows multiple containers and services to be configured and run using a single command. It saves time, reduces mistakes, and makes the deployment process more organized and repeatable.
2. What happens if you make an indentation error (like using a Tab instead of Spaces) in a YAML file?
An indentation error can cause the YAML file to become invalid, resulting in an error when running Docker Compose. YAML requires proper indentation using spaces, so the file must be corrected before the services can run successfully.
3. Why did we use environment variables (like MYSQL_PASSWORD) in the Compose file?
We used environment variables like MYSQL_PASSWORD to configure the database securely and conveniently without hardcoding settings directly into the application configuration. They also make it easier to change passwords and other settings when needed.
4. How did it feel to deploy a fully functional enterprise cloud storage system (Nextcloud) in just a few minutes?
It felt exciting and satisfying because I was able to deploy a fully functional cloud storage system in just a few minutes. This activity helped me realize how Docker and containerization make deploying applications faster, easier, and more efficient.

Since Mission 1, my understanding of Cloud Computing has improved.
